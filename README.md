# Travelgram

Uma landing page moderna e visualmente elegante para um perfil de viagens, inspirada em redes sociais e portfólios fotográficos. O projeto apresenta uma vitrine de imagens, dados do viajante e uma identidade visual clean, com foco em experiências, cultura e descoberta.

## 🎯 Objetivo

Criar uma interface de apresentação para um perfil de viajante, com destaque para:

- imagens de destinos e memórias de viagem;
- perfil pessoal com localização e estatísticas;
- navegação simples e visual minimalista;
- experiência responsiva e moderna em HTML e CSS.

## ✨ Funcionalidades

- Layout premium com foco em fotos e storytelling;
- Cabeçalho com identidade visual e navegação;
- Seção de perfil do usuário com localização e dados;
- Galeria de imagens em grade responsiva;
- Rodapé com informações complementares;
- Estrutura leve e fácil de personalizar.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- SVG e imagens estáticas

## 🚀 Como executar

### Opção 1: abrir diretamente no navegador

Basta abrir o arquivo `index.html` em qualquer navegador moderno.

### Opção 2: executar um servidor local

Se preferir visualizar em um ambiente mais próximo de um projeto web, execute:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```text
http://localhost:8000
```

## 🧩 Personalização

Você pode adaptar facilmente:

- textos do perfil;
- nome e descrição do viajante;
- localidade e estatísticas;
- imagens da galeria;
- cores e tipografia no diretório `styles/`.
